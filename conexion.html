☁️ Base de datos compartida — ET35

Conectá la página escolar y la terminal QR a la misma base de datos, incluso si las abrís desde equipos diferentes. No hace falta Node.js.

Volver al sistema

Esta página guarda la URL, la clave pública y una sesión de acceso en este navegador; no guarda la contraseña. La clave service_role / secret NUNCA debe colocarse acá.

Preparación (una sola vez)
  1. Creá un proyecto en Supabase.
  2. En SQL Editor, ejecutá el contenido del archivo INSTALAR_BASE_DATOS.sql del ZIP.
  3. En Authentication → Users, creá una cuenta de prueba con correo y contraseña. Si la confirmación de email está habilitada, confirmala.
  4. Copiá la Project URL y la clave pública desde las opciones de API y completá los campos de arriba.
  5. En la segunda computadora o celular, abrí la misma web y conectá el mismo proyecto y la misma cuenta. Los cambios aparecerán automáticamente.
Uso permitido: solamente datos ficticios. Esta integración conserva la autenticación escolar de prueba; no es una solución segura para datos personales reales.
